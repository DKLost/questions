# 核心原理

> 由作者手写核心语义，除本文档外的文档为AI生成，仅作参考。

- **抽象（Abstract）** 
  - 说明 ⇒ 也称概念或理念，从对任意的Being的抽象而来。
  - 形式化 ⇒ **(P B)**，表示一个｢∀P A B｣的匿名抽象A
- **现象（Phenomenon）** 
  - 说明 ⇒ 三元组｢谓词 主词 宾词｣
  - 抽象构造时会自动添加
- **谓词（predicate）** 
  - 说明 ⇒ 也是一种抽象。
- **复合谓词构造** 
  - 说明 ⇒ 三元组<左谓词 中心概念 右谓词>
- **通用抽象**
  - 专名 ⇒ Abstract
  - 说明 ⇒ 因为通用具象被简化，而使用的通用抽象。
- **~ **
  - 说明 ⇒ 谓词逆构算子
  - 形式化 ⇒  `{~ <P_L I P_R>} = <P_R I P_L>`
- **(∃)**  
  - 说明
    - 抽象存在量化算子，目前使用的存在量化方式。
    - 由于采用简化系统，有以下特点
      - 所有用户输入的 **pred** 概念上都表示 **∃pred∃**、但只写作 **pred**；
      - 内部 **is-a** 概念上表示 **∀is-a**、但只写作**is-a**。
      - **∃** 与 **∀** 两符号在简化系统中均不出现。
  - 形式化
    - 左(∃) ⇒  `(∃)Pred = <∀is-a Abstract pred>`
    - 右(∃) ⇒ `Pred(∃) = <~Pred Abstract ∀is-a>`

  - 笔记用法
    - 符号':' ⇒ 表示右(∃)
    - 符号'@' ⇒ 表示左(∃)
- **∃has∃**
  - 说明 ⇒ 有向关联谓词，表达主宾词间的有向关联性，在笔记中出现的**has**实际都表示**∃has∃**
    - ':'左的默认谓词为**has** 
    - '@'左的默认谓词为**~has**
- **∃is∃**
  - 说明 ⇒ 识别谓词，在笔记中出现的**is**实际都表示**∃is∃**
  - 笔记用法
    - '⇒' 后的默认谓词为**is**
- **∀is-a**
  - 说明 ⇒ 全称is-a谓词，表达全称的is-a关系，在系统中内部生成的用**is-a**表示**∀is-a**
- **A→pred:[B]**
  - 说明 ⇒ 派生抽象链名形式，**^**内涵算子目前在系统中的替代品。
- **A→pred**
  - 说明 ⇒ 派生谓词链名形式，对于**<P_L I P_R>**，写作**~P_L:[I]→P_R**。
- **指象（signify‌）**
  - 说明
    - 从一个指定Abstract出发，能经过某谓词到达另一Abstract的结构。
    - 当谓词为is时，这一过程特化为identify。
    - 例如给定宾词B，谓词P，从而找到所有满足｢P A B｣的A，这一过程就叫做指象。
    - 复习的重复间隔记忆过程，认为是发生在指象过程中的。
  - 形式化
    - 指象**[P B]**，表示满足｢P ? B｣的主词位的所有存在。



### 被简化的部分（未实现）

- **具象（Being）**
  - 说明 ⇒ 被简化不使用，事实上，抽象同样是一种具象，本质区别只在于是否有以∀谓词的现象边。
  - 形式化 ⇒ {P B}，表示一个满足｢P A B｣的匿名具象A
- **has**
  - 说明 ⇒ 真正的has有向关联谓词，被简化不使用。
- **is**
  - 说明 ⇒ 真正的is识别谓词，被简化不使用
- **is-a**
  - 说明 ⇒ 真正的is-a，被简化不使用
- **通用具象** ⇒ Being
  - 说明 ⇒ 被简化不使用
- **∃** 
  - 说明 ⇒ 具象存在量化，被简化不使用
- **^**
  - 说明 ⇒ 内涵算子，被简化不使用。
- 内涵合并
  - 说明 ⇒ 同内涵的存在会合并为一个存在。
- 现象折叠谓词构造
  - 具象折叠 ⇒ `<P_L {∀is b} P_R>`
  - 抽象折叠 ⇒ `<P_L {∀is-v {^is b}} P_R>`
- **v**
  - 说明 ⇒ 外延算子
- 现象边UnFold
  - 过程 ⇒  `｢<P_L I P_R> A B｣ ⇒ 存在C，｢is-a C I｣,｢P_L C A｣,｢P_R C B｣`
- **¬**
  - 说明 ⇒ 否定算子 q
  
- **¬、∀、∃、v、^**的谓词构造形式化
  - `{¬ p} = <¬~is-v Being ^p>`
  - `{∀ p} = <^is-a Being p> `
  - `{∃ p} = <is-a Being p>`
  - `{v p} = <is-v Being p>`
  - `{^ p} = <^is-v Being p>`
  - `is-a = {~ {∃ {~ is}}}` 
  - `is-v = {~ {v {~ is}}}` 
  - `^is-a = <^is-v Being is-a> `
  - 原子谓词 ⇒ `is-a` 、`is-v` 、`^is-a`、`^is-v`、`¬~is-v`
