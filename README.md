- questions
  - 描述 ⇒ 题库型学习软件
  - 核心思路 ⇒ 以填空作答用时反推知识掌握程度
  - 算法 ⇒ FSRS(间隔重复)
  - 参照软件 ⇒ anki
  - 平台 ⇒ Qt6桌面应用
  - 数据存储 ⇒ SQLite本地文件
  - 特色 ⇒ 用知识图谱组织知识点
  - 三区
    - 知识索引区
      - 内容 ⇒ 现象树
      - 功能
        - 检索
        - 增删改
        - 复制
        - 移动
    - 题目表
      - 内容 ⇒ 全部题目
      - 功能 ⇒ 按概念子树或名称过滤
    - 题面与答案区
      - 内容 ⇒ 题面、填空列表
      - 功能 ⇒ 编辑题面、管理填空
  - 知识图谱
    - 抽象
      - 载体 ⇒ abstracts-表
      - 身份 ⇒ 名字
    - 现象
      - 载体 ⇒ phenomena表
      - 结构 ⇒ ｢谓词 主语 宾语｣
    - 链名
      - 形式 ⇒ A→pred:[B]
      - 特点 ⇒ 逐层嵌套
    - (∃)形式
      - 两种 ⇒ 右(∃)-冒号行 与 左(∃)-at行
      - 区别 ⇒ 存在量化落点相反
    - 锚点
      - 用途 ⇒ 连接概念与实体
      - 形式 ⇒ is-a-锚点对
    - 合并 ⇒ 其规则是 : 唯一的is子行折叠显示为合并箭头
    - 建树 ⇒ 其特点是 : 批量载入-零写库
  - 功能
    - 复习
      - 入口 ⇒ 单项、表项全部、表项待学
      - 形态 ⇒ 遮罩、门控、乱序池、四档自评
    - 提前复习 ⇒ 粒度分为 : 当前空、当前题、当前过滤表
    - 宾词视图
      - 入口 ⇒ ctrl+左键-右键菜单
      - 作用 ⇒ 以该行宾词为顶层再看一遍
    - 清除孤立概念
      - 入口 ⇒ 工具栏刷子按钮-知识树右键菜单
      - 作用 ⇒ 删掉只为声明而生、无下级、无引用的顶层空壳概念
    - 笔记导入
      - 入口 ⇒ parser按钮
      - 副作用 ⇒ 会先清空知识库再重建
    - 公式
      - 渲染方式 ⇒ typst实时编译为图
    - 题面资产 ⇒ 种类 : 表格-图片-描述条目
  - 快捷键
    - F1 ⇒ 用于 : 添加答案-以选中文本为初值
    - F2 ⇒ 用于 : 添加答案并转为填空下划线
    - F3 ⇒ 用于 : 添加描述条目
    - F4 ⇒ 用于 : 添加typst公式
    - F5 ⇒ 用于 : 按当前填空编号自动编号下一个填空
    - F6 ⇒ 用于 : 切换选中部分的下划线
  - 构建
    - 套件 ⇒ Qt-6.11.2-MinGW-64bit
    - 工程 ⇒ questions.pro
    - 外部工具 ⇒ typst.exe需自备
    - 数据库 ⇒ 运行目录的-question.db与knowledge.db
  - 目录
    - core ⇒ 知识引擎与题库访问
    - dialogs ⇒ 全部对话框
    - widgets ⇒ 可复用控件-知识树渲染
    - services ⇒ 答案存取-题面预览
    - parser ⇒ 缩进笔记解析
    - utils ⇒ 通用工具函数
    - docs ⇒ 设计文档与手册
  - 文档
    - 00-核心原理 ⇒ 语义内核
    - 附图 ⇒ docs目录下的图谱.png、展开流程.png、简化示例.png
  - 自举
    - 要点 ⇒ 本README本身就是这种笔记
    - 用法 ⇒ 点parser按钮，粘贴本文件
      - 副作用 ⇒ 会先清空知识库再重建
      - 效果 ⇒ 整个项目成为知识图谱
  - 神经网络
    - prednet是一个谓词神经网络的简单实现，相当于relate过程，供参考。
